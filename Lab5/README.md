# Online Store - Lab 5

## Описание
Проект интернет-магазина на Angular, разделенный на компоненты с поддержкой категорий, лайков и удаления товаров.

## Функционал
- 4 категории товаров по 5 позиций в каждой (итого 20 товаров).
- Фильтрация по категориям.
- Кнопка "Лайк" с инкрементом счетчика.
- Удаление товара из списка через EventEmitter (@Output).
- Ссылки на реальные товары Kaspi.kz и возможность поделиться в мессенджерах.

## Инструкция по запуску
1. Убедитесь, что у вас установлен Node.js и Angular CLI.
2. Склонируйте репозиторий.
3. Выполните команду `npm install` для установки зависимостей.
4. Запустите проект командой `ng serve`.
5. Откройте браузер по адресу `http://localhost:4200/`.
